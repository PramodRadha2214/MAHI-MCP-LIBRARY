## Review status definitions

- **Unreviewed** — discovered but not assessed.
- **Reviewed** — source, license, setup, and basic risks checked.
- **Tested** — installation and core functions tested in a controlled environment.
- **Deprecated** — no longer recommended; retain notes for migration.

## Entry requirements

Every entry must include an official source URL, repository/license information where available, installation method, configuration schema or example, required permissions, credential handling, maintenance evidence, known limitations, compatibility, and a date of last verification.

Use [the entry template](CATEGORIES/MCP-ENTRY-TEMPLATE.md).
