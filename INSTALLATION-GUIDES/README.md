# Installation Guides

Add one guide per MCP server or a clearly defined family of servers.

Each guide should include:

1. Official source and release/version used.
2. Supported operating systems and prerequisites.
3. Verified installation steps.
4. Client-specific configuration.
5. Environment-variable setup with placeholders only.
6. Permission and network requirements.
7. Safe test procedure and rollback/uninstall steps.
8. Troubleshooting and known limitations.

Never publish actual tokens, API keys, passwords, machine-specific private paths, or personal data.
